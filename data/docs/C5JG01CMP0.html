2. Identification des pièces

Le pare-chocs arrière est composé de 5 parties :
  • Le pare-chocs arrière latéral gauche (1)
  • Le pare-chocs arrière gauche (5)
  • Le pare-chocs arrière central (2)
  • Le pare-chocs arrière droit (4)
  • Le pare-chocs arrière latéral droit (3)
3. Dépose
Débrancher la batterie.
3.1. Pare-chocs arrière latéral
Effectuer les opérations ci-dessous des deux côtés du véhicule.
Figure : c5jg0icd
Déposer les vis (6).
Déclipper : Le pare-chocs arrière latéral (3) ; À l’aide de l’outil [1350-ZZ].
Dégager : Le pare-chocs arrière latéral (3).
Figure : c5jg0idd
Déconnecter le connecteur  (en "a").
Déposer : Le pare-chocs arrière latéral (3).
NOTA : Prévoir le remplacement des agrafes .
