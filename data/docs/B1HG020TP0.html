B1HG020TP0Dépose - Repose : Capteur de pression d’air d’admission
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Implantation
Figure : b1hg37ad
Le capteur pression d’air d’admission est situé sur le répartiteur d’air (en "a").
2. Dépose
Débrancher la batterie.
Figure : b1hg37gd
Déposer :
  • Le pare-chocs central supérieur (2)
  • Le pare-chocs central inférieur (1)
  • La traverse (3)
  • Le cache-style moteur
Figure : b1hg37md
Déposer les vis (5).
Écarter le conduit d’air (4).
Figure : b1hg37pd
Déconnecter le connecteur (en "b").
Déposer :
  • L’écrou (6)
  • Le capteur de pression d’admission d’air (7)
3. Repose
Reposer :
  • Le capteur de pression d’admission d’air (7)
  • L’écrou (6)
Reconnecter le connecteur  (en "b").
Repositionner le conduit d’air (4).
Reposer :
  • Les vis (5)
  • Le cache-style moteur
  • La traverse (3)
  • Le pare-chocs central inférieur (1)
  • Le pare-chocs central supérieur (2)
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
