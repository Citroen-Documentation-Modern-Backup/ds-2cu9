C5GG010XP0Dépose - repose : Garniture de pavillon
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350-ZZ.
2. Opérations préliminaires
Effectuer les opérations suivantes :
  • Couper le contact
  • Attendre 3 minutes avant de débrancher la batterie
  • Débrancher la batterie
Déposer :
  • Les garnitures supérieures de pied arrière  (gauche et droit)
  • La garniture droite de vitre de panneau gauche
  • Les vide-poches
  • Les plafonniers
  • L’enjoliveur de pulseur d’air arrière
  • Le joint d’entrée de porte latérale coulissante
  • Le joint d’entrée de portes arrière
3. Dépose
3.1. Garniture de pavillon (côté gauche)
Figure : c5gm0dcd
Déclipper les agrafes  (en "a") ; À l’aide de l’outil [1].
Déposer : La garniture de pavillon (1).
3.2. Garniture de pavillon ( côté droit)
Figure : c5gm0ddd
Déclipper les agrafes  (en "b") ; À l’aide de l’outil [1].
Déposer : La garniture de pavillon (2).
3.3. Garniture de pavillon
Figure : c5gm0ded
Déclipper :
  • Les agrafes  (en "c") ; À l’aide de l’outil [1]
  • Le connecteur  (en "d")
Déconnecter le connecteur  (en "e").
Dégager le faisceau électrique (3).
Déposer : La garniture de pavillon (4).
3.4. Supports de garniture centrale de pavillon
Figure : c4dm068d
Déposer :
  • Les vis (5), (7)
  • Les supports de garniture centrale (6), (8), (9)
3.5. Faisceau électrique
Figure : d3am003d
NOTA : Repérer le cheminement du faisceau électrique .
Décoller - Déposer : Le faisceau (10).
3.6. Aérateurs de garniture centrale de pavillon
Figure : c5dm031d
Déclipper : Les aérateurs (11) (en "f").
Déposer : Les aérateurs (11).
4. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Serrer les vis (5), (7) à 2 ± 0,1 m.daN.
Vérifier le fonctionnement des équipements électriques.
