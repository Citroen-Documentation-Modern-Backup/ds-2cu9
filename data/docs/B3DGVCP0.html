B3DGVCP0Dépose - repose : Moyeu arrière
1. Outillage préconisé
Figure : e5ap2y9d
Repère Désignation Référence Référence
[1] outil à freiner 5709-T.E (coffret 5709-T) (-).0619E (coffret (-).0619)
2. Dépose
Débloquer les vis de roues (arrière).
Lever et caler le véhicule, roues arrière pendantes.
Déposer :
  • Les roues arrière
  • Le bouchon de moyeu
  • Le disque de frein  (voir opération correspondante)
Figure : b3fp7l8d
Défreiner l’écrou (1).
Déposer :
  • L’écrou (1)
  • Le moyeu arrière (2)
3. Repose
Reposer :
  • Le moyeu arrière (2)
  • L’écrou (1)
NOTA : Utiliser un écrou neuf.
Serrer l’écrou (1) à 45 ± 1,5 m.daN.
Figure : b3fp7l9d
Freiner l’écrou (1) ; À l’aide de l’outil [1].
Le méplat "a" de l’outil doit toujours être dirigé vers l’extérieur.
Figure : b2fp06nd
ATTENTION : La jupe de l’écrou doit être freinée dans le sens opposé au serrage.
4. Opération complémentaire
Reposer :
  • Le disque de frein  (voir opération correspondante)
  • Les roues
Remettre le véhicule sur ses roues.
Serrer les vis de roues .
