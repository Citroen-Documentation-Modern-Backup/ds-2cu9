B1HK010XP0Nettoyage : Raccords sur rampe d’injection commune haute pression carburant
1. Outillage
Matériels :
  • Dégraissant SODIMAC N°35
  • Pinceau
  • Bac de nettoyage
  • Aspirateur
  • Embout rond
2. Opérations préliminaires
Débrancher la borne négative de la batterie.
Protéger l’alternateur.
3. Mode opératoire
Figure : b1hk1003d
Nettoyage des zones de réparation (en "a") :
  • Verser le produit dégraissant SODIMAC N°35 dans le bac de nettoyage
  • Tremper le pinceau dans le produit dégraissant SODIMAC N°35 ou équivalent
  • Nettoyer le point "a" et aspirer simultanément ; À l’aide de l’aspirateur et de l’embout rond
  • Nettoyer l’aspirateur après utilisation
