B1BG0101P0Démontage - Remontage : Bielles - pistons
1. Démontage
Figure : b1bpscnd
ATTENTION : Repérer l’orientation de la bielle par rapport au piston.
Déposer :
  • Les joncs d’arrêt (1), (5)
  • L’axe de piston (4)
  • Le piston ( 3)
  • Les segments ( 2)
  • Le demi-coussinet (6)
  • La bielle
Procéder de la même manière pour les trois autres ensembles.
2. Remontage
Figure : b1dm001d
ATTENTION : La tête de bielle en "b" doit être positionnée du côté de l’empreinte de gicleur sur le piston (en " a").
NOTA : La face marquée "TOP" des segments doit être orientée vers le haut.
Huiler :
  • Le demi-coussinet (6)
  • L’axe de piston (4)
Reposer :
  • Les segments ( 2)
  • Le jonc d’arrêt (1)
  • La bielle (7)
  • L’axe de piston (4)
  • Le jonc d’arrêt (5)
  • Les demi-coussinets (6) (sur bielle)
Procéder de la même manière pour les trois autres ensembles.
