C4BS011NP0Déshabillage - Habillage : Benne basculante
BENNE BASCULANTE GRUAU DEPUIS OPR 13111
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Déshabillage
1.1. Ridelle latérale
Figure : c4bs06rd
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Ouvrir la ridelle latérale (3).
Desserrer les vis (2) sans les déposer.
Glisser les gonds (1) (Suivant les flèches ).
Déposer la ridelle latérale (3).
NOTA : Opérations symétriques.
Figure : c4bs06vd
Déposer :
  • Les gonds (1)
  • Les écrous (4)
  • Les poignées (5)
NOTA : Opérations symétriques.
1.2. Ridelle arrière
Déposer les crochets de sécurité de ridelle arrière .
Figure : c4bs06wd
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Déverrouiller les articulations (6).
Déposer la ridelle arrière (7).
Figure : c4bs06xd
Desserrer les vis (8) sans les déposer.
Déposer les fixations d’articulation (9) de la ridelle arrière (7).
1.3. Porte échelle
Figure : c4bs06yd
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Déposer :
  • Les vis (11)
  • Le porte-échelle (10)
1.4. Charnières de ridelle latérale
Figure : c4bs06zd
Déposer :
  • Les vis (13)
  • Les charnières de ridelle latérale (12)
NOTA : Opérations symétriques.
1.5. Fond de benne
Déposer le fond de benne .
1.6. Arrêt de charge
Figure : c4bs071d
Déposer :
  • Les vis (15)
  • L’arrêt de charge (14)
1.7. Pieds
Figure : c4bs072d
Déposer :
  • La vis (17) de chaque pied (16)
  • Les pieds (16)
2. Habillage
2.1. Arrêt de charge
Figure : c4bs073d
ATTENTION : Nettoyer et dégraisser les zones de collage.
Appliquer un cordon d’adhésif joint sur la largeur du fond de benne (18) (en "a", "b").
Figure : c4bs071d
Poser l’arrêt de charge (14).
Serrer les vis (15) à 4 m.daN.
2.2. Fond de benne
Poser le fond de benne .
2.3. Pied
Figure : c4bs072d
Poser les pieds (16).
ATTENTION : Contrôler la perpendicularité des pieds par rapport au fond de benne.
Serrer les vis (17) de chaque pied (16) à 6 m.daN.
2.4. Charnières de ridelle latérale
Figure : c4bs076d
ATTENTION : Respecter l’orientation des charnières de ridelle latérale (12).
Poser les charnières de ridelle latérale (12).
Serrer les vis (13) à 2 m.daN.
NOTA : Opérations symétriques.
2.5. Ridelle latérale
Figure : c4bs077d
NOTA : Respecter l’orientation des gonds (1). Les poignées doivent se manœuvrer avec facilité, mais ne doivent pas être libres. Graisser les points d’ancrage.
Prémonter les gonds (1) sans serrer les vis (2) et les glisser dans la ridelle latérale.
Reposer les poignées (5).
Serrer l’écrou (4) en butée, puis revenir d’environ 1/4 de tour.
NOTA : Opérations symétriques.
Figure : c4bs078d
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
ATTENTION : Graisser les gonds (1).
Positionner les gonds (1) en butée sur les charnières (12) de ridelle latérale (3) (en "c").
Mettre en appui la ridelle latérale (3) sur le fond de benne (suivant flèches).
Serrer les vis (2) à 2 m.daN.
NOTA : Opérations symétriques.
2.6. Ridelle arrière
Poser les crochets de sécurité de ridelle arrière .
Figure : c4bs07ad
Prémonter les fixations d’articulation (9) sans serrer les vis (8) et les glisser dans la ridelle arrière (7).
NOTA : Face lisse à l’intérieur.
Figure : c4bs07bd
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
ATTENTION : Graisser les points d’ancrage de la ridelle arrière.
Engager les fixations d’articulation (9).
Verrouiller les articulations (6).
Serrer les vis (8) à 2 m.daN.
2.7. Porte échelle
Figure : c4bs06yd
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Reposer le porte-échelle (10).
Serrer les vis (11) à 4 m.daN.
