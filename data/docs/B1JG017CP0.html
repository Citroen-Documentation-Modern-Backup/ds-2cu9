B1JG017CP0Dépose - Repose : Collecteur d’échappement
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI).
1. Outillage
Matériel : Bac à vidange.
2. Dépose
Caler et lever le véhicule sur un élévateur à 2 colonnes.
Débrancher la batterie.
Déposer la protection sous moteur .
Vidanger le circuit de refroidissement moteur.

  • Les bras d’essuie-glaces
  • La grille d’auvent (1)
  • La prise d’air (2)

Déposer :
  • Le filtre à air complet (3)
  • Le tube d’air (4)
  • Le conduit (5)
Figure : b1kg08cd
Déposer :
  • L’ensemble vanne de recyclage des gaz d’échappement (EGR) et échangeur thermique (6)
  • Le tube (7)
Figure : b2cg1atd
Désaccoupler le tube (8).
Écarter : Les câbles de commande de boîte de vitesses (9).
Figure : b1jg0j2d
Déposer :
  • Les écrous (10)
  • Les écrous (11)
Comprimer légèrement le flexible d’échappement (12) pour dégager les goujons de l’ensemble catalyseur/pot de détente.
Déposer le flexible d’échappement (12).
Figure : b1jg0j5d

Déposer :
  • La vis de fixation (15) (Catalyseur )
  • Le collier d’échappement (13)
  • Le catalyseur (14)
Figure : b1jg0j8d
Déposer le support (18) (Catalyseur ).
ATTENTION : Ne pas désolidariser la vanne de régulation de pression du turbocompresseur ni desserrer les fixations de celle-ci.
Déconnecter :
  • Le connecteur (en "c")
  • Le tube de commande de régulation de turbocompresseur (en "d")
Désaccoupler et écarter :
  • Le conduit d’air (19)
  • Le tube de retour d’huile turbocompresseur (17)
  • Le raccord (16) du tube de refroidissement turbocompresseur
Figure : b1jg0jbd
ATTENTION : Obturer les conduits de graissage et de retour d’huile sur le turbocompresseur et le moteur.
Désaccoupler :
  • Le raccord (23) du tube de graissage turbocompresseur (21) de la culasse
  • Le raccord (20) du tube de graissage turbocompresseur (21) sur le turbocompresseur
Déposer :
  • Le tube de refroidissement turbocompresseur (22)
  • Le tube de graissage du turbocompresseur (21)
Figure : b1jg0jed
Déposer :
  • Les 10 écrous de fixation du collecteur d’échappement  (en "e")
  • Les entretoises
  • Les 3 goujons  (en "f")
Désaccoupler l’ensemble (24) collecteur d’échappement/turbocompresseur du moteur.
Engager l’ensemble (24) collecteur d’échappement/turbocompresseur sous le tablier moteur.
ATTENTION : Brider l’ensemble (24) collecteur d’échappement/turbocompresseur sur le moteur pour éviter la chute de l’ensemble collecteur d’échappement/turbocompresseur.
Lever le véhicule.
Débrider l’ensemble (24) collecteur d’échappement/turbocompresseur.
Déposer l’ensemble (24) collecteur d’échappement/turbocompresseur.
Figure : b1jg0jhd
Déposer : Les écrous (25) (À l’établi).
Désaccoupler le collecteur d’échappement du turbocompresseur (26).
3. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Moteur
  • Ligne d’échappement
ATTENTION : Si les goujons de fixation du turbocompresseur (26) sont déposés, les reposer enduits de loctite frenetanch.
NOTA : Remplacer systématiquement les joints déposés.
Reposer :
  • Le turbocompresseur (26) sur le collecteur d’échappement
  • Les écrous (25)
Serrer les écrous (25) (À l’établi).
Reposer l’ensemble (24) collecteur d’échappement/turbocompresseur.
Accoupler l’ensemble (24) collecteur d’échappement/turbocompresseur au moteur.
Reposer :
  • Les 3 goujons  (en "f")
  • Les entretoises
  • Les 10 écrous de fixation du collecteur d’échappement  (en "e")
  • Le tube de graissage du turbocompresseur (21)
  • Le tube de refroidissement turbocompresseur (22)
Accoupler :
  • Le raccord (20) du tube de graissage turbocompresseur (21) sur le turbocompresseur
  • Le raccord (23) du tube de graissage turbocompresseur (21) de la culasse
Accoupler et repositionner :
  • Le raccord (16) du tube de refroidissement turbocompresseur
  • Le tube de retour d’huile turbocompresseur (17)
  • Le conduit d’air (19)

  • Le tube de commande de régulation de turbocompresseur (en "d")

  • Le collier d’échappement (13)
  • La vis de fixation (15) (Catalyseur )

Déposer :
  • Le flexible d’échappement (12)
  • Les écrous (11)
  • Les écrous (10)
Repositionner : Les câbles de commande de boîte de vitesses (9).
Accoupler le tube (8).
Reposer :
  • Le tube (7)
  • L’ensemble vanne EGR et échangeur thermique (6)
  • Le conduit (5)
  • Le tube d’air (4)
  • Le filtre à air complet (3)
Connecter le connecteur  (en "a").
Reposer :
  • La prise d’air (2)
  • L’auvent (1)
  • Les bras d’essuie-glaces
Remplir et purger le circuit de refroidissement moteur.
Reposer la protection sous moteur .
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
