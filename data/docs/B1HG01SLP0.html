B1HG01SLP0Dépose - Repose : turbocompresseur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI) .
ATTENTION : Ne pas désolidariser la vanne de régulation de pression du turbocompresseur ni desserrer les fixations de celle-ci.
Caler et lever le véhicule sur un élévateur à 2 colonnes.
Débrancher la batterie de servitude .
Déposer la protection sous moteur .
Vidanger le circuit de refroidissement moteur.
Lever le véhicule.

Déposer :
  • Les essuie-glace complets
  • L’auvent (1)
  • La prise d’air (2)
Figure : b1hg1v4d
Déconnecter le connecteur  (en "a").
Déposer :
  • Le filtre à air complet (3)
  • Le tube d’air (4)
  • Le débitmètre (5)
Figure : b1kg08cd
Déposer :
  • L’ensemble vanne EGR et échangeur thermique (6)
  • Le tube (7)
Figure : b2cg1atd
Désaccoupler le tube (8).
Écarter les câbles de commande de boîte de vitesses (9).
Figure : b1bg1fjd
Déposer :
  • Le précatalyseur
  • Le support du précatalyseur (12)
Déconnecter :
  • Le connecteur ( en "b")
  • Le tube de commande de régulation de turbocompresseur ( en "c")
Désaccoupler et écarter :
  • Le conduit d’air (13)
  • Le tube de retour d’huile turbocompresseur (11)
  • Le raccord (10) du tube de refroidissement turbocompresseur
Descendre le véhicule.
Figure : b1bg1fkd
ATTENTION : Obturer les conduits de graissage et de retour d’huile sur le turbocompresseur et le moteur.
Désaccoupler :
  • Le raccord (17) du tube de graissage turbocompresseur (15) de la culasse
  • Le raccord (14) du tube de graissage turbocompresseur (15) sur le turbocompresseur
Déposer :
  • Le tube de refroidissement turbocompresseur (16)
  • Le tube de graissage du turbocompresseur (15)
Figure : b1bg1fld
Déposer :
  • Les 10 écrous du collecteur d’échappement ( en "d")
  • Les entretoises
  • Les 3 goujons  (en "e")
Désaccoupler l’ensemble (18) collecteur d’échappement/turbocompresseur du moteur.
Engager l’ensemble (18) collecteur d’échappement/turbocompresseur sous le tablier moteur.
ATTENTION : Brider l’ensemble (18) collecteur d’échappement/turbocompresseur sur le moteur pour éviter la chute de l’ensemble collecteur d’échappement/turbocompresseur.
Lever le véhicule.
Débrider l’ensemble (18) collecteur d’échappement/turbocompresseur.
Déposer l’ensemble (18) collecteur d’échappement/turbocompresseur.
Figure : b1bg1fmd
Déposer (à l’établi) :
  • Les écrous (19)
  • Le turbocompresseur (20)
2. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Si les goujons de fixation du turbocompresseur (20) sont déposés, les reposer enduits de loctite frenetanch.
Remplacer systématiquement les joints déposés.
Reposer :
  • Le turbocompresseur (20) sur le collecteur d’échappement
  • Les écrous (19)
Serrer les écrous (19).
Repositionner l’ensemble (18) collecteur d’échappement/turbocompresseur sur le moteur.
Reposer :
  • Les goujons  (en "e")
  • Les entretoises
  • Les 10 écrous du collecteur d’échappement (en "d")
  • Le tube de refroidissement turbocompresseur (16)
  • Le tube de graissage du turbocompresseur (15)
Serrer les raccords (14), (17).
Reconnecter :
  • Le connecteur ( en "b")
  • Le tube de commande de régulation de turbocompresseur ( en "c")
ATTENTION : Vérifier l’absence de corps étranger dans les conduits d’air.
Accoupler :
  • Le raccord (10) du tube de refroidissement turbocompresseur (16)
  • Le tube de retour d’huile turbocompresseur (11)
  • Le conduit d’air (13)
Reposer :
  • Le support du précatalyseur (12)
  • Le précatalyseur
Repositionner les câbles (9) de commande de boîte de vitesses.
Accoupler le tube (8).
Reposer :
  • Le tube (7)
  • L’ensemble vanne EGR et échangeur thermique (6)
  • Le débitmètre (5)
  • Le tube d’air (4)
  • Le filtre à air complet (3)
Reconnecter le connecteur ( en "a").
Reposer :
  • La prise d’air (2)
  • L’auvent (1)
  • Les essuie-glace complets
  • La protection sous moteur
Remplir et purger le circuit de refroidissement moteur.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie de servitude.
Rebrancher la batterie de servitude .
