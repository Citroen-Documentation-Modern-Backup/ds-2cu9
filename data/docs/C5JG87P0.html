2. Dépose
IMPERATIF : Inhiber la suspension pneumatique avant toute opération de levage du véhicule (Pont élévateur 2 ou 4 colonnes, cric d’atelier ou cric de bord).
Figure : c4bp1sqd
Le pare-chocs arrière est composé de 5 parties :
  • Le pare-chocs droit (1)
  • Le pare-chocs latéral droit (2)
  • Le pare-chocs central (3)
  • Le pare-chocs latéral gauche (4)
  • Le pare-chocs gauche (5)
2.1. Pare-chocs latéral
Figure : c4cp1wud
Déposer :
  • Les vis (6), (7)
  • Le pare-chocs latéral droit (2)
Déclipper les agrafes du pare-chocs latéral droit (2) ; À l’aide de l’outil [1].
Répéter l’opération sur le côté opposé.
NOTA : Prévoir le remplacement des agrafes .

  • Les feux arrière  (voir opération correspondante)
