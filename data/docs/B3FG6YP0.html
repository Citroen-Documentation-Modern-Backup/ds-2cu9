B3FG6YP0Dépose - repose : Disque de frein arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Remplacer systématiquement les plaquettes de frein lors du remplacement des disques.
1. Dépose
Débloquer les vis de roues arrière.
Desserrer le frein de stationnement .
Lever et caler le véhicule, roues arrière pendantes.
Déposer les roues arrière.
Figure : b3fp7k6d
Déposer :
  • Les plaquettes de frein arrière (voir opération correspondante)
  • Les vis (1)
  • L’étrier de frein arrière (2)
Figure : b3fg244d
Déposer :
  • Les vis (3)
  • Le disque de frein arrière (4)
2. Nettoyage
IMPERATIF : Ne pas utiliser d’air comprimé pour nettoyer les freins.
2.1. 1ère possibilité
Nettoyer le disque de frein arrière (4) et l’étrier de frein arrière (2) ; À l’aide d’un produit nettoyant frein recommandé.
Laisser sécher et égoutter.
Essuyer à l’aide d’un chiffon papier.
2.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué (voir catalogue équipements et matériels).
3. Repose
ATTENTION : Respecter les couples de serrage .
Nettoyer parfaitement les faces d’appui disque de frein arrière (4)/moyeu.
Reposer :
  • Le disque de frein arrière (4)
  • Les vis (3)
Serrer les vis (3).
Reposer :
  • L’étrier de frein arrière (2)
  • Les vis (1) (neuves) (préenduites de frein filet)
Serrer les vis (1).
Reposer : Les plaquettes de frein arrière (voir opération correspondante).
Donner plusieurs coups de frein, moteur en marche, avant de faire rouler le véhicule.
Vérifier le fonctionnement des freins.
Reposer les roues arrière.
Remettre le véhicule sur ses roues.
Serrer les vis de roue .
