3. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Remplacer : Le tube d’alimentation haute pression carburant (2) (neuf).
ATTENTION : Remplacer systématiquement les joints déposés (neufs).
Reposer :
  • Le régulateur de pression carburant (8) (Avec un joint neuf)
  • Les vis (9)
Repositionner : La pompe haute pression carburant (7).
Reposer :
  • Les vis (6)
  • La vis (5)
Accoupler le tuyau d’arrivée de carburant (4).
Connecter le connecteur en "c".
Reposer le tube d’alimentation haute pression carburant (2) (neuf).
Serrer les raccords "a", "b" (à la main).
Reposer la vis (3) et la patte de fixation du tuyau d’alimentation haute pression carburant (2).
Serrer :
  • Le raccord "a" : À l’aide de la clé à tuyauter Facom de type "crowfoot" (18 mm)
  • Le raccord "d" : À l’aide de la clé à tuyauter Facom de type "crowfoot" (19 mm)
Reclipper : La goulotte (1) de faisceau électrique.
Reposer le véhicule sur ses roues.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
4. Contrôle d’étanchéité
ATTENTION : Pulvériser un détecteur de fuite ARDROX 9D1 BRENT sur les raccords "a", "b" (Tuyau haute pression carburant (2)).
Laisser sécher le produit.
Démarrer le moteur.
Vérifier l’absence de fuites.
Accélérer jusqu’à un régime de 4000 tr/mn.
Vérifier l’absence de fuites.
Faire un essai routier.
Vérifier l’absence de fuites.
Remplacer les pièces défectueuses (si nécessaire).
Reposer : Les protections sous moteur (avant).
