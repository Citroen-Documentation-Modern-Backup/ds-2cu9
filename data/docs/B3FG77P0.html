1. Outillage
outil Référence Désignation
Figure : e5ab09ut
 [0172-Z] pince pour collier élastique
2. Dépose
Vidanger le réservoir de liquide de frein ; À l’aide d’une seringue.
Figure : b3fp7mpd
Déconnecter le connecteur ( en "a").
Désaccoupler :
  • Le collier (2) ; À l’aide de l’outil [0172-Z]
  • Le tuyau d’alimentation (3) de l’émetteur d’embrayage
  • Les tuyaux de frein (4) (prévoir l’écoulement du liquide de frein)
Obturer ; À l’aide de bouchons :
  • Les orifices des organes hydrauliques
  • Le tuyau d’alimentation (3) de l’émetteur d’embrayage
Déposer :
  • Le réservoir de liquide de frein (1)
  • Les écrous (5)
  • Le maître-cylindre de frein (6)
3. Repose
ATTENTION : Respecter les couples de serrage .
NOTA : Contrôler le retrait de la tige de poussée de l’amplificateur de frein.
Figure : b3fp7mqd
Poser un joint neuf (7).
Reposer :
  • Le maître-cylindre de frein (6)
  • Les écrous (5)
  • Le réservoir de liquide de frein (1)
Déposer les obturateurs .
Accoupler :
  • Les tuyaux de frein (4)
  • Le tuyau d’alimentation (3) de l’émetteur d’embrayage
  • Le collier (2) ; À l’aide de l’outil [0172-Z]
Reconnecter le connecteur ( en "a").
Remplir et purger le circuit de freinage .
