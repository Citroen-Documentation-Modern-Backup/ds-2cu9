B3FG70P0Dépose - repose : Segments de frein de stationnement
1. Outillage préconisé
Figure : e5ap2xrd
[1] pince de dépose-pose des ressorts de segments de frein FACOM 196 TS 2110-T.
2. Dépose
Débloquer les vis de roues (arrière).
Desserrer le frein de stationnement .
Lever et caler le véhicule, roues arrière pendantes.
Déposer :
  • Les roues arrière
  • Le disque de frein arrière (voir opération correspondante)
  • Le moyeu arrière (voir opération correspondante)
Figure : b3fp7kud
Déposer :
  • Le mécanisme de réglage (1)
  • Le ressort (5)
  • Les épingles de retenue (3)
  • Les garnitures de frein (2)
  • Le ressort (4) ; À l’aide de l’outil [1]
3. Nettoyage
IMPERATIF : Ne pas utiliser d’air comprimé pour nettoyer les freins.
3.1. 1ère possibilité
Nettoyer le disque de frein et l’étrier de frein à l’aide d’un produit nettoyant frein recommandé.
Laisser sécher et égoutter.
Essuyer à l’aide d’un chiffon papier.
3.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué (voir catalogue Équipements et Matériels).
4. Repose
Reposer :
  • Les garnitures de frein (2)
  • Les épingles de retenue (3)
  • Le ressort (4) ; À l’aide de l’outil [1]
  • Le ressort (5)
  • Le mécanisme de réglage (1)
Nettoyer parfaitement les faces d’appui disque/moyeu.
Reposer :
  • Le moyeu arrière (voir opération correspondante)
  • Le disque de frein arrière (voir opération correspondante)
Régler le frein de stationnement  (voir opération correspondante).
Donner plusieurs coups de frein, moteur en marche, avant de faire rouler le véhicule.
Vérifier le fonctionnement des freins.
Reposer les roues arrière.
Remettre le véhicule sur ses roues.
Serrer les vis de roue .
