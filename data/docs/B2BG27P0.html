B2BG27P0Dépose - repose : Commande hydraulique d’embrayage
BVM6 OU BVM5
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Déposer l’ensemble filtre à air et conduit d’entrée d’air.
ATTENTION : Repérer le niveau de liquide de frein dans le réservoir avant intervention.
Enlever le bouchon du réservoir de liquide de frein .
1.1. Montage avec cylindre récepteur de commande hydraulique d’embrayage
Figure : b2bi00jd
ATTENTION : L’extrémité du tuyau transparent doit être plongée dans le liquide de frein.
Vidanger le circuit de commande hydraulique d’embrayage :
  • Accoupler un tuyau transparent sur la valve de purge (1)
  • Plonger l’extrémité du tuyau transparent dans un récipient contenant du liquide de frein, situé plus bas que le cylindre récepteur de commande hydraulique d’embrayage
  • Appuyer sur l’agrafe de verrouillage (2)
  • Tirer le clip (3) d’un cran dans le sens de la flèche (position ouverte)
1.2. Montage avec butée hydraulique
Figure : b2bg046d
Accoupler un tuyau transparent sur la valve de purge (4).
ATTENTION : L’extrémité du tuyau transparent doit être plongée dans le liquide de frein.
Plonger l’extrémité du tuyau transparent dans un récipient contenant du liquide de frein, situé plus bas que la purge du circuit de commande hydraulique d’embrayage.
Ouvrir la valve de purge (4).
Actionner la pédale d’embrayage manuellement pour vidanger le circuit de commande hydraulique d’embrayage.
Fermer la valve de purge (4).
Désaccoupler le tuyau transparent de la valve de purge (4).
2. Dépose
Déposer :
  • Le cache sous le volant
  • Le tapis de plancher
Figure : b3fb06ud
Premier montage :
  • Tourner l’axe (5) d’un quart de tour dans le sens antihoraire
  • Déposer l’axe (5)
Deuxième montage :
  • Déposer le circlips
  • Déposer l’axe (5)
Désolidariser la tige de poussée de l’émetteur de commande hydraulique d’embrayage de la pédale d’embrayage.
Figure : b2bg06nd
Désaccoupler :
  • Le collier (6)
  • Le tuyau d’alimentation (10) de l’émetteur de commande hydraulique d’embrayage (7)
NOTA : Obturer le tuyau d’alimentation (10) de l’émetteur de commande hydraulique d’embrayage (7).
Déposer l’agrafe (8).
Désaccoupler la canalisation de commande hydraulique d’embrayage (9).
NOTA : Obturer la canalisation de commande hydraulique d’embrayage (9).
Déposer l’émetteur de commande hydraulique d’embrayage (7) (tourner d’un quart de tour dans le sens antihoraire).
2.1. Montage avec cylindre récepteur de commande hydraulique d’embrayage
Figure : b2bg047d
Déposer :
  • Les 2 vis (12)
  • Le cylindre récepteur de commande hydraulique d’embrayage (11)
Figure : b2bg06od
Déposer la vis (14).
Écarter le support (15).
Déposer le tuyau (13).
2.2. Montage avec butée hydraulique
Figure : b2bg06pd
Déposer :
  • Le raccord (16)
  • Les vis (18)
  • La butée hydraulique (17)
3. Repose
Graisser (selon montage) :
  • La rotule de la tige du cylindre émetteur  (graisse ESSO NORVA 275)
  • L’embout de la tige du cylindre récepteur  (graisse MOLYKOTE BR2 PLUS)
3.1. Montage avec cylindre récepteur de commande hydraulique d’embrayage
Passer le tuyau (13) dans le support (15).
Refermer le support (15).
Reposer :
  • La vis (14)
  • Le tuyau (13)
Refermer toutes les agrafes tenant le tuyau (13).
Reposer :
  • Le cylindre récepteur de commande hydraulique d’embrayage (11)
  • Les 2 vis (12)
Repousser le clip (3).
Tirer sur l’agrafe de verrouillage (2).
3.2. Montage avec butée hydraulique
Reposer :
  • Le raccord (16)
  • La butée hydraulique (17)
  • Les vis (18)
3.3. Opérations suivantes
Reposer l’émetteur de commande hydraulique d’embrayage (7) (Tourner d’un quart de tour dans le sens horaire).
Accoupler :
  • Le tuyau d’alimentation (10) sur l’émetteur de commande hydraulique d’embrayage (7)
  • Le collier (6)
  • La canalisation de commande hydraulique d’embrayage (9)
Reposer l’agrafe (8).
Accoupler la tige de poussée de l’émetteur de commande hydraulique d’embrayage avec la pédale d’embrayage.
Premier montage :
  • Reposer l’axe (5)
  • Verrouiller l’axe (5) d’un quart de tour dans le sens horaire
Deuxième montage :
  • Reposer l’axe (5)
  • Reposer le circlips
Reposer :
  • Le cache sous le volant
  • Le tapis de plancher
4. Opérations complémentaires
Remplir le réservoir de liquide de frein au maximum de sa capacité.
Purger le circuit de commande hydraulique d’embrayage  (voir opération correspondante).
Ramener le niveau de liquide de frein au niveau relevé précédemment.
Remettre le bouchon du réservoir de liquide de frein.
Reposer l’ensemble filtre à air et conduit d’entrée d’air.
