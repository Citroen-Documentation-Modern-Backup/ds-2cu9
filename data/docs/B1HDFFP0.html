2. Dépose
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI).
Placer le véhicule sur un pont élévateur à 2 colonnes.
Déposer :
  • La protection sous moteur
  • La protection sous moteur droite
Figure : b1hp2eqd
Déposer :
  • Les écrous (1)
  • Le collier (2)
Débrancher et écarter le conduit d’air (3) du refroidisseur d’air de suralimentation.
3. Contrôle
Figure : b1hp2erd
Interposer le manchon pour contrôle [ 2] muni du manchon adaptateur [3], entre le conduit d’air (3) et le refroidisseur d’air de suralimentation (4).
Figure : b1hp2esd
Raccorder le manomètre [ 1] sur le manchon pour contrôle [2] avec un tube (en "a").
Placer le manomètre [ 1] à l’intérieur du véhicule.
IMPERATIF : Respecter les conditions de contrôle suivantes : Moteur à température de fonctionnement ; Véhicule en état de marche.
Démarrer le moteur.
Accélérer progressivement.
Accélérer le moteur à pleine charge.
Contrôler la pression : 1,1 ± 0,1 bar.
Déposer les outils [ 1 - 2 - 3].
4. Repose
Rebrancher le conduit d’air (3) sur le refroidisseur d’air de suralimentation (4).
ATTENTION : Poser un collier ( 2) neuf.
Reposer :
  • Le collier (2)
  • Les écrous (1)
  • La protection sous moteur droite
  • La protection sous moteur
Replacer le véhicule sur le sol.
